# Restaurant Analytics Dashboard | Excel

##  Project Overview
This project focuses on analyzing restaurant data using Microsoft Excel to understand restaurant ratings, online delivery availability, price ranges, and city-wise restaurant distribution.

An interactive Excel dashboard was created to present key metrics and business insights through KPIs and visualizations.

##  Project Objectives
- Analyze restaurant distribution by rating category.
- Understand online delivery availability.
- Explore restaurant distribution across different price ranges.
- Identify cities with the highest number of restaurants.
- Present insights through an interactive Excel dashboard.

## 🛠️ Tools & Skills
- Microsoft Excel
- Pivot Tables
- Excel Charts
- Data Analysis
- Data Visualization
- KPI Reporting
- Data Cleaning

##  Dashboard Visualizations
1. **Restaurant Count by Rating Category**  
   Analyzes the distribution of restaurants across rating categories.

2. **Online Delivery Availability**  
   Shows the percentage of restaurants offering online delivery.

3. **Restaurant Distribution by Price Range**  
   Compares restaurants across different price categories.

4. **Top 10 Cities by Restaurant Count**  
   Identifies cities with the highest restaurant concentration.

##  Key Insights
- The dataset contains 9,551 restaurant records.
- The average rating of rated restaurants is 3.44.
- Approximately 25.66% of restaurants offer online delivery.
- Approximately 74.34% of restaurants do not offer online delivery.
- Restaurant distribution varies across rating and price categories.
- City-wise analysis helps identify major restaurant locations.
